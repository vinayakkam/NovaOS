# TwilightOS: project notes for Claude

Arch-based distro (archiso) with a KDE Plasma 6.8 desktop styled after the owner's
own Twilight desktop (github.com/vinayakkam/twilight-desktop): Windows 11 layout,
macOS conveniences. Renamed from "NovaOS" on 2026-11-21 (that name was taken).

## Hard rules
- **Everything on D:** (installs, caches, VMs, downloads). Ask before admin, reboots,
  Windows features, or deleting anything. Exception already approved: VirtualBox lives
  in `C:\Program Files\Oracle\VirtualBox` (7.x refuses user-writable install dirs).
- **No AI attribution**: never add Co-Authored-By / "Generated with" lines or credit
  Claude in commits, PRs, metadata or comments. Authors are "TwilightOS Project".
- Desktop is **KDE Plasma**, not Hyprland (Hyprland was tried and rejected).
- No Microsoft or Apple logos, fonts, icons or wallpapers. All TwilightOS art is original
  (icons generated by `theme/icons/generate.mjs`); Denali wallpaper is public domain.
- Target: live session **under 1 GB RAM**. Owner judges visuals harshly: always
  screenshot and check before calling something done.

## Build & test
```powershell
.\scripts\build-iso.ps1      # ISO -> out\twilightos-<date>-x86_64.iso (~3 GB, ~10-15 min)
.\scripts\test-vm.ps1        # recreates VM "TwilightOS-Test" (EFI, 4 CPU, 6 GB, VMSVGA) and boots
```
- Power the VM off before rebuilding (it locks the ISO).
- `build-iso.sh` builds `packages/*/PKGBUILD` (currently onlyoffice-bin) into a
  build-time `[twilightos]` repo (cached in `/var/tmp/twilightos-build/repo`).
- mkarchiso resets file modes: every executable added to airootfs must be listed in
  `iso/profiledef.sh` `file_permissions`.
- Symlinks in airootfs live in `iso/symlinks.list` (NTFS can't hold them).
- Lint: QML syntax via `qmllint` in WSL (only syntax is checkable; Plasma imports
  aren't installed there). **Watch for `Behavior on` a `readonly` property**: it
  silently breaks the whole widget (bit us twice in the Start menu).

### Fast iteration in the running VM (no rebuild)
- Shared folder: `VBoxManage sharedfolder add TwilightOS-Test --name twilightos --hostpath D:\Projects\twilightos --transient --readonly`,
  then in the VM: `sudo mount -t vboxsf -o ro twilightos /mnt/twilightos`.
- `out/vmtools/hotfix.sh` copies plasmoids/apps/lock/logout QML over the live system;
  then `systemctl --user restart plasma-plasmashell`.
- Keyboard into the VM: `VBoxManage controlvm TwilightOS-Test keyboardputstring|keyboardputscancode`
  (Ctrl+Alt+T opens Konsole). Screenshots: `controlvm ... screenshotpng`.
- Logs/diagnostics go out through the serial port: VM COM1 -> `D:\VirtualBox\VMs\TwilightOS-Test\serial.log`
  (write with `... | sudo tee /dev/ttyS0`). `twilightos-memreport.timer` writes `free -m`
  + top RSS there every minute (VirtualBox only).

## What exists (repo map)
- `iso/` archiso profile (from releng): packages, NetworkManager, SDDM autologin as
  `twilight` (passwordless live user), zram, journald cap, `copytoram=n`, masked
  kaccess / X11 bridges / KDE Connect autostart, timezone from `$TIMEZONE`
  (default Asia/Kolkata), pacman hook `90-twilightos-logout.hook`.
- `theme/` look-and-feel `org.twilightos.desktop` (layout script), Twilight colour scheme,
  `/etc/xdg` defaults, skel, SDDM theme `twilightos`, logout + lock screen QML,
  icon theme `TwilightOS`, terminal greeting (fastfetch + TwilightOS block logo).
- Logout/lock screens: Plasma 6.8 loads them from the shell package, so
  `twilightos-sync-shell` keeps a full copy in `/usr/local/share/plasma/shells/...`
  with only TwilightOS QML swapped in (re-synced on every plasma-desktop update).
- `plasmoids/`: `org.twilightos.startmenu` (Kicker RootModel for all apps,
  SimpleFavoritesModel for pins, RunnerModel for search), `org.twilightos.activewindow`,
  `org.twilightos.topclock`, `org.twilightos.meters` (CPU/RAM bars + popup with graphs).
- `apps/settings` TwilightOS Settings (QML via `/usr/lib/qt6/bin/qml` + shell helper),
  `apps/taskmanager` (ksysguard ApplicationDataModel + sensors), Rust stubs
  `quicklook`/`winlayer`, Tauri stub `welcome`.
- `packages/onlyoffice-bin` repackaged official v10.0.0 .deb (sha256 pinned).

- `apps/setup` **TwilightOS Setup**, the installer: `Main.qml` (Windows-Setup-style
  steps: language/time zone/keyboard, disk, account, summary, progress, done) and
  `twilightos-install` (root backend via the live user's sudo). It wipes the chosen
  disk: GPT, 1 GB ESP (UEFI) or BIOS-boot partition, btrfs root with `@ @home
  @snapshots @var_log @pkg` (zstd), unsquashfs of the ISO's airootfs.sfs, strips the
  live bits (live user service, NOPASSWD sudoers, SDDM autologin, memreport,
  archiso mkinitcpio conf), user + wheel sudo, locale/time/keymap, mkinitcpio,
  GRUB (EFI + removable fallback, or i386-pc) with the TwilightOS theme, Snapper.
  Progress: `/run/twilightos-install/progress` ("percent|message"), log next to it.
- GRUB theme: `theme/grub/theme.txt` + `scripts/make-grub-theme.sh` (background from
  Denali, 9-slice menu pixmaps, Inter pf2 fonts). Used by the ISO (UEFI bootmode
  `uefi.grub`, `iso/grub/grub.cfg`) and copied to `/usr/share/grub/themes/twilightos`
  for installed systems. BIOS ISO boot is still syslinux.
- Light mode: `theme/colors/TwilightLight.colors`; every widget/app uses
  Kirigami.Theme colours, so they follow light/dark.
